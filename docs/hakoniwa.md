# 箱庭（Hakoniwa）

Rustbound の製品定義。完了済み。

バニラ同等の無限生成や完全 AI は目標にしない。固定サイズの箱庭で、軽量に Minecraft Java 1.20.1 クライアントと遊べることを完成条件とする。

## 製品定義

現世／ネザー／エンドの固定マップをサイズ3種まで同梱する。歩行・破壊・次元移動が可能であり、Mob は簡易、液体は静的、コンテナは最低限とする。地形生成アルゴリズムは実装しない。バイナリは小さく保つ。

## サイズ

チャンク半径はスポーン中心の正方形（一辺 = `2 * radius + 1` チャンク）。

| 名前 | チャンク半径 | 一辺チャンク | ブロック幅（約） |
|------|-------------|-------------|------------------|
| `tiny` | 4 | 9×9 | 144 |
| `small` | 8 | 17×17 | 272 |
| `medium` | 16 | 33×33 | 528 |

各サイズについて overworld / nether / end の組み込みデータを同梱する。  
`{level}/packs/{size}[-nether|-end].rbpk` があればそちらを優先する。同梱データは `data/hakoniwa/packs/`。

## 実装メモ

- ポータル: 現世西 glowstone → ネザー、東 end stone → エンド。帰還は各次元西の glowstone。`/dim` でも切替可。転送後しばらくポータル無効。
- Mob: 現世にブタ／ウシ／ゾンビ、ネザーにゾンビ化ピグリン、エンドにエンダーマン。
- 液体: 流動なし。水・溶岩は非固体。溶岩は接触ダメージ。泳ぎ演出はクライアント側。
- コンテナ: スポーン北のチェストを右クリックで開く。内容は `{level}/chests.bin` に保存。

## ビルドサイズ目安

| ビルド | 目安 |
|--------|------|
| `cargo build -p rustbound-server --release` | 約 1 MB |
| `cargo build -p rustbound-server --profile dist` | 約 0.7 MB |
| `data/hakoniwa/packs/`（全サイズ×3次元） | 約 0.4 MB |

パック再生成: `cargo run -p rustbound-server --example write_packs`

## 設定

```properties
hakoniwa-size=tiny
allow-nether=true
```

## クリーンルーム

マップは自前生成、または利用者が手元で用意したワールドを読む前提とする。  
Minecraft / Forge jar・逆コンパイル・mappings はリポジトリに入れない（[AGENTS.md](../AGENTS.md)）。
